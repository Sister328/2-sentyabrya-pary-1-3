# Python — Классы и объекты — 7 сентября

В репозитории находятся решения заданий 1–20 по уроку о классах и объектах Python.

## Кратко по уроку

- **Класс** — шаблон для создания объектов.
- **Объект (экземпляр)** — конкретный экземпляр класса.
- **Атрибут класса** — общее свойство, заданное внутри класса.
- **Локальный атрибут** — свойство конкретного объекта, записывается через `self`.
- `__dict__` показывает атрибуты текущего пространства имён.
- `setattr(obj, name, value)` создаёт/изменяет атрибут.
- `getattr(obj, name, default)` получает атрибут, а при отсутствии может вернуть `default`.
- `hasattr(obj, name)` проверяет наличие атрибута.
- `del` и `delattr()` удаляют атрибут.
- **Метод** — функция внутри класса.
- `self` — ссылка на объект, из которого вызван метод.
- `__init__` автоматически вызывается при создании объекта и обычно создаёт его локальные свойства.
- `__del__` вызывается перед удалением объекта.
- Класс может хранить данные и действия над этими данными.
