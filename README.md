# 2-sentyabrya-pary-1-3

Практические задачи по ООП: классы, объекты, методы, инкапсуляция, наследование и полиморфизм.

## Структура
- `task1` — класс Cat, объекты и вывод информации
- `task2` — метод `draw()` для Cat
- `task3` — инкапсуляция температуры двигателя
- `task4` — инкапсуляция координат и масштаба Graph
- `task5` — базовый класс Figure
- `task6` — наследование Line, Rect, Ellipse
- `task7` — полиморфизм через `draw()`
- `task8` — расширение системы классом Triangle
- `task9` — мини-графический редактор

## Запуск
Откройте нужную папку в терминале и выполните:

```bash
python main.py
```

Если команда `python` не работает, попробуйте `python3 main.py`.
