# Мини-графический редактор

## 1. Название и описание задачи

Мини-графический редактор демонстрирует три основных принципа ООП: инкапсуляцию, наследование и полиморфизм.

Программа создаёт круги и квадраты, хранит их координаты внутри базового класса `Figure`, вычисляет площадь каждой фигуры и выводит общую площадь всех фигур.

## 2. Архитектура проекта

### Инкапсуляция

Базовый класс `Figure` скрывает координаты через внутренние атрибуты `_Figure__x` и `_Figure__y` (они создаются конструкцией `__x` и `__y`).

Доступ к координатам выполняется через публичные методы:
- `get_coords()` — получить координаты;
- `set_coords()` — изменить координаты.

### Наследование

Классы `Circle` и `Square` наследуются от базового класса `Figure`.

Схема:

```text
Figure
├── Circle
└── Square
```

### Полиморфизм

В базовом классе объявлен метод `calculate_area()`.

Классы `Circle` и `Square` реализуют этот метод по-разному:
- у круга площадь вычисляется по формуле `π × r²`;
- у квадрата площадь вычисляется по формуле `a²`.

В главной программе используется один цикл для объектов разных типов:

```python
for figure in figures:
    area = figure.calculate_area()
```

## 3. Пример использования

```python
circle = Circle((0, 0), 5)
square = Square((10, 10), 4)

print(circle.get_coords())
print(square.get_coords())

circle.set_coords((5, 5))

print(circle.calculate_area())
print(square.calculate_area())
```

## 4. Результат работы
